# Security policy

Please use [GitHub's private vulnerability reporting](https://github.com/ElevenID/git-agent/security/advisories/new)
for suspected security issues. Do not open a public issue with exploit details
or include working credentials or private project data in a report.

Include the affected version or commit, a minimal reproduction, expected and
observed behavior, and any relevant platform details. Maintainers will assess
the report and coordinate a fix and disclosure.
